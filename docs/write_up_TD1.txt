Profil de chaque workload (d'après l'énoncé) :
- cpu_task    -> CPU intensif, compte des nombres premiers (repeated numerical tests)
- memory_task -> mémoire intensive, alloue et parcourt une grosse zone mémoire
- matrix_task -> CPU + mémoire, calcul matriciel dense
- sort_task   -> mixte, génère et trie une grosse collection d'entiers (optionnel pour TD1)

Le paramètre --size a un sens différent selon le workload : nombre max testé pour cpu_task, taille en Mo pour memory_task, dimension de la matrice pour matrix_task, nombre d'éléments à trier pour sort_task.

#!/bin/bash
# scripts/benchmark.sh
#
# Script tout simple pour lancer un workload plusieurs fois
# et enregistrer le temps + la mémoire utilisée dans un CSV.
#
# Comment l'utiliser (3 arguments, dans cet ordre) :
#   ./benchmark.sh cpu_task 500000 3
#   ./benchmark.sh memory_task 256 3
#
#   1er argument = nom du workload (cpu_task, memory_task, matrix_task, sort_task)
#   2e argument  = la taille (--size)
#   3e argument  = combien de fois on répète le test

# On récupère les 3 arguments et on leur donne un nom clair
WORKLOAD=$1
SIZE=$2
REPETITIONS=$3

# On construit le chemin vers l'exécutable, ex: bin/cpu_task
PROGRAMME="bin/$WORKLOAD"

# Vérification simple : est-ce que le fichier existe ?
if [ ! -f "$PROGRAMME" ]; then
    echo "Erreur : je ne trouve pas $PROGRAMME"
    echo "As-tu bien compilé les workloads avec go build ?"
    exit 1
fi

# On s'assure que le fichier CSV existe et a bien son en-tête
if [ ! -f "data/benchmark_local.csv" ]; then
    echo "workload,size,run,runtime_s,max_rss_kb" > data/benchmark_local.csv
fi

echo "Je lance $WORKLOAD avec --size $SIZE, $REPETITIONS fois"

# Boucle : on répète le test REPETITIONS fois
for run in $(seq 1 $REPETITIONS); do

    echo "  -> essai numero $run"

    # On lance le programme avec /usr/bin/time -v
    # -v donne des infos detaillees (temps, memoire)
    # On met tout ca dans un fichier temporaire pour le relire juste apres
    /usr/bin/time -v "$PROGRAMME" --size "$SIZE" > /dev/null 2> resultat_temp.txt

    # On cherche la ligne du temps ecoule, ex: "0:00.06"
    TEMPS=$(grep "Elapsed" resultat_temp.txt | awk '{print $NF}')

    # On cherche la ligne de la memoire max utilisee, ex: "2432"
    MEMOIRE=$(grep "Maximum resident set size" resultat_temp.txt | awk '{print $NF}')

    # On ajoute une ligne dans le CSV avec toutes ces infos
    echo "$WORKLOAD,$SIZE,$run,$TEMPS,$MEMOIRE" >> data/benchmark_local.csv

    # On supprime le fichier temporaire, on n'en a plus besoin
    rm resultat_temp.txt

done

echo "Termine ! Regarde data/benchmark_local.csv"

annalyse fiat dans benchmark_annalyse.xlsx :

=AVERAGEIFS($D$2:$D$28;$A$2:$A$28;H2;$B$2:$B$28;I2)

AVERAGEIFS veut dire "moyenne avec plusieurs conditions" (AVERAGE = moyenne, IFS = si plusieurs conditions sont vraies). Elle prend toujours cette structure :

AVERAGEIFS(colonne_à_moyenner ; colonne_condition_1 ; valeur_1 ; colonne_condition_2 ; valeur_2 ; ...)

Découpons ta formule morceau par morceau :

Morceau	Rôle
$D$2:$D$28	La colonne qu'on veut moyenner : runtime_s
$A$2:$A$28	Première colonne à vérifier : workload
H2	La valeur attendue dans cette colonne (ex: cpu_task)
$B$2:$B$28	Deuxième colonne à vérifier : size
I2	La valeur attendue dans cette colonne (ex: 200000)
